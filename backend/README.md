# Бэкенд: банк вопросов и тестирование (Laravel 10)

Серверная часть мультиагентной системы генерации заданий и проверки развёрнутых ответов. Все 12 экранов прототипа работают на настоящей базе MySQL. Нейросети пока нет: агенты сделаны как заготовки, которые отвечают шаблонами и простыми эвристиками, но уже встроены в конвейер, очередь и API.

Стек: PHP 8.1, Laravel 10, MySQL 8.0, Apache через OSPanel 5. Node.js нужен только для сборки фронта через Vite.

## Запуск в OSPanel

Проект физически лежит в `D:\ProgramsGames\OSPanel\domains\ptp.localhost`, а `D:\Claude\ПТП Диплом\backend` — ссылка (junction) на эту папку: Apache в OSPanel не открывает сайты через ссылки, поэтому настоящая папка должна быть внутри `domains`. В списке доменов OSPanel (`userdata\profiles\Default_domains.txt`) есть строка `ptp.localhost;\ptp.localhost\public`, копия списка до изменения — `Default_domains.txt.bak-before-ptp`. Адреса вида `*.localhost` браузер открывает сам, даже если OSPanel не смог записать файл hosts.

1. Запустите OSPanel (модули Apache 2.4 + PHP 8.1 и MySQL 8.0 уже выбраны в профиле).
2. В phpMyAdmin создайте базу `ptp_diploma`, сравнение `utf8mb4_unicode_ci`. Пользователь `root` без пароля, как в `.env`.
3. Откройте консоль OSPanel («Дополнительно → Консоль») и выполните:
   ```
   cd /d "D:\Claude\ПТП Диплом\backend"
   php artisan migrate --seed
   ```
4. Откройте http://ptp.localhost и войдите (учётки ниже). Преподаватель попадает на «Обзор», студент — на «Мои тесты».

Если база уже была заполнена раньше, чем появился вход, пересоздавать её не нужно — достаточно добавить учётки:
```
php artisan db:seed --class=AccountsSeeder
```

Если домен не открывается, проверьте в настройках OSPanel на вкладке «Домены», что режим «Ручное + автопоиск» и что ptp.localhost есть в списке.

Пересоздать базу с демо-данными с нуля: `php artisan migrate:fresh --seed`.

Фронт уже собран в `public/build`. После правок в `resources/js` или `resources/css` пересоберите его: `npm install` один раз, затем `npm run build`. Для разработки с автообновлением — `npm run dev`.

## Демо-данные

Сидер (`database/seeders/DemoSeeder.php`) берёт данные прототипа из `database/seeders/data/demo.json` (это `frontend/assets/js/mock-data.js`, сохранённый в JSON) и добавляет:

## Вход и учётные записи

| Роль | Почта | Пароль |
|---|---|---|
| Преподаватель (Бакановская Л. Н.) | `teacher@utmn.local` | `teacher123` |
| Студент (Иванов А., Группа 1) | `student@utmn.local` | `student123` |

Учётки создаёт `database/seeders/AccountsSeeder.php`. Остальные 62 студента группы нужны только для статистики, войти под ними нельзя. Пароли простые, потому что это локальный стенд; на странице входа подсказка с ними видна только при `APP_ENV=local`.

Новую учётку можно создать из консоли, пароль команда спросит отдельно:
```
php artisan user:create petrov@utmn.local "Петров П." --role=student --group="Группа 1"
php artisan user:create ivanova@utmn.local "Иванова Е. А." --role=teacher
```

Как устроено:
- обычный вход Laravel по сессии (`app/Http/Controllers/AuthController.php`), «Запомнить меня», не больше 10 попыток входа в минуту;
- роль хранится в `users.role`, проверку делает middleware `role:teacher` / `role:student` (`app/Http/Middleware/EnsureRole.php`): чужие страницы перенаправляют на свою главную, чужие запросы к API получают 403;
- API работает на той же сессии, что и страницы, с CSRF-токеном из `<meta name="csrf-token">`;
- проверка ответа в тренировке (`/api/questions/{код}/check`) открыта только для вопросов тренировочных тестов, чтобы ею нельзя было подобрать ответы к идущему тесту.

### Что работает по-настоящему

- Загрузка материалов (файлы в `storage/app/materials`, ссылки, вставленный текст), удаление, повторное распознавание.
- Банк вопросов: фильтры, правка, одобрение и отклонение (поштучно и массово), история изменений.
- Сборка теста по матрице «тип × сложность» из одобренных вопросов и публикация.
- Прохождение теста: попытка хранится на сервере, ответы сохраняются автоматически, таймер идёт по времени сервера.
- Оценка: варианты ответа проверяются сразу; SQL-запрос выполняется в учебной базе (SQLite в памяти, только SELECT) и сравнивается с результатом эталона; развёрнутый ответ получает предварительную оценку агента и попадает в очередь преподавателю.
- Подтверждение оценки преподавателем пересчитывает балл попытки, студент видит итог.
- Аналитика по тесту считается по попыткам: распределение, темы, проблемные вопросы.

### Заготовки агентов (место для нейросети)

Интерфейсы лежат в `app/Agents/Contracts`, заготовки — в `app/Agents/Fake`, выбор реализации — в `app/Providers/AgentServiceProvider.php` по `AGENTS_DRIVER` из `.env`.

| Агент | Интерфейс | Что делает заготовка |
|---|---|---|
| Извлечение текста, OCR | `TextExtractor` | TXT читает по-настоящему; файлы со словом «скан» в имени считает сканами без текста до нажатия «Распознать» |
| Аналитик | `AnalystAgent` | подбирает темы курса по словам из названия материала |
| Составитель | `WriterAgent` | пишет вопросы по шаблонам с пометкой «[заготовка]» |
| Критик | `CriticAgent` | формальные проверки (один верный вариант, есть критерии и эталон) и детерминированные «сомнения» |
| Каталогизатор | `CatalogAgent` | теги по теме и сложности, поиск дублей по похожести текста |
| Оценщик | `GraderAgent` | ищет в ответе слова из критериев и эталона, подсвечивает найденные предложения |
| Экзаменатор | `ExaminerAgent` | случайный выбор по матрице, «лестница» сложности для адаптивного режима |

Чтобы подключить нейросеть:

1. Заполните в `.env` `LLM_API_URL`, `LLM_API_KEY`, `LLM_MODEL`. Клиент `app/Agents/Llm/HttpLlmClient.php` уже умеет обращаться к любому OpenAI-совместимому API (облако, LM Studio, Ollama, vLLM).
2. Напишите классы, например `app/Agents/Llm/LlmWriterAgent.php`, которые реализуют те же интерфейсы и получают `LlmClient` в конструкторе.
3. Добавьте драйвер `llm` в `AgentServiceProvider::DRIVERS` и поставьте `AGENTS_DRIVER=llm`.
4. Для долгой генерации переключите очередь: `QUEUE_CONNECTION=database`, `php artisan queue:table`, `php artisan migrate`, и держите запущенным `php artisan queue:work`. Экран «Работа агентов» уже опрашивает прогресс каждые 2 секунды.

## API

Все адреса требуют входа. Работа с банком, материалами, агентами, тестами и проверкой — только для преподавателя; попытки и тренировка — только для студента; учебная база SQL — для обоих.

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/questions?status=&type[]=&difficulty[]=&topic[]=&material=&q=` | список вопросов с фильтрами |
| GET / PATCH | `/api/questions/{код}` | вопрос, правка и смена статуса |
| POST | `/api/questions/bulk` | `{ids, action: approve\|reject}` |
| POST | `/api/questions/{код}/regenerate` | Составитель переписывает, Критик проверяет заново |
| POST | `/api/questions/{код}/check` | проверка ответа в тренировке |
| GET / POST | `/api/materials` | список, загрузка (`file`, `url` или `text`) |
| POST | `/api/materials/{id}/ocr` | распознать скан |
| DELETE | `/api/materials/{id}` | удалить, если по материалу нет вопросов |
| POST | `/api/generation-runs` | запустить агентов |
| GET | `/api/generation-runs/{id}` | состояние конвейера и журнал |
| GET | `/api/bank-stats` | сколько одобренных вопросов по темам |
| POST | `/api/tests` | собрать и опубликовать тест |
| POST | `/api/tests/{код}/questions` | добавить вопросы из банка в тест |
| PATCH | `/api/reviews/{id}` | подтвердить оценку открытого ответа |
| PUT | `/api/attempts/{id}` | автосохранение попытки |
| POST | `/api/attempts/{id}/submit` | сдать попытку |
| POST | `/api/sql/run` | выполнить запрос в учебной базе |

## Что пока не сделано

- Регистрация и восстановление пароля (учётки создаёт сидер или команда `user:create`).
- Настоящие агенты, извлечение текста из PDF/DOCX/PPTX и OCR.
- Импорт и экспорт в Moodle XML, апелляции студентов, отмена запуска агентов.
- Laravel 10 больше не получает обновлений безопасности, а Composer по умолчанию блокирует пакеты с уязвимостями. Чтобы установить его на PHP 8.1, в `composer.json` отключена эта блокировка (`audit.block-insecure: false`). Для защиты диплома это не мешает; для публичного сервера нужен PHP 8.2+ и Laravel 11 или новее.
