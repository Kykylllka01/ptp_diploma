# ПТП Диплом

Мультиагентная система генерации заданий и проверки развёрнутых ответов (ВКР, ТюмГУ, ИСиТ).

| Папка | Что внутри |
|---|---|
| `backend/` | Laravel 10 (PHP 8.1, MySQL 8): экраны преподавателя и студента, API, ИИ-агенты на DeepSeek. Инструкция по запуску — `backend/README.md` |
| `frontend/` | Тестовый фронт на HTML/CSS/JS по прототипу (моки, без сервера) |
| `архитектура/` | Проект ИИ-части и разбор требований научного руководителя |

Секреты (ключ LLM, доступ к БД) хранятся только в `backend/.env`, который не попадает в репозиторий. Шаблон — `backend/.env.example`.
